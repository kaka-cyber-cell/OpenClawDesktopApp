⟩ 常见问题

OpenClawDesktopApp 是什么？

OpenClawDesktopApp 是 OpenClaw AI Agent 框架的 Windows 一键安装包。它内置了 Node.js、Playwright 和所有依赖项，让您无需任何终端命令即可在飞书、WhatsApp 和 Telegram 上部署 AI 机器人。

支持哪些 AI 大模型？

支持 5+ 大模型供应商，包括 DeepSeek V3/R1、OpenAI GPT-4o/o1/o3、Anthropic Claude 3.5 Sonnet 和 Google Gemini 2.0 Flash。在图形界面中一键即可切换。

需要 Node.js 或编程知识吗？

完全不需要。OpenClawDesktopApp 专为非技术用户设计。所有依赖项都已打包在安装程序中。

OpenClawDesktopApp 免费吗？

是的，完全免费下载和使用。您仅需为 DeepSeek 或 OpenAI 等供应商的 AI 模型 API 调用付费。

支持哪些聊天平台？

支持飞书 (Lark)、WhatsApp、Telegram 和 Discord。每个频道都可以通过图形化仪表盘进行可视化配置。

我的数据安全吗？

绝对安全。所有 API 密钥和配置数据仅存储在您的本地设备。不会向任何第三方云服务器传输凭据或聊天数据。
